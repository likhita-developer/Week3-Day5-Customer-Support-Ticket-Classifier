Observation

The character n-gram model produced the same performance as the word-level
model for category classification.

For priority classification, the character n-gram model improved both
accuracy and macro F1 compared with the word-level baseline. This suggests
that character-level features can capture useful patterns in the ticket
text, although priority classification remains challenging because of
class imbalance and limited urgency information.
